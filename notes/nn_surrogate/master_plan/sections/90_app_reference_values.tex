\paragraph{Derived iteration numbers.}
Exactly ten years before 2180 is iteration $2{,}987{,}040$, which is not a
multiple of 1464, so no restart exists there. Use the nearest checkpoint below it
and lengthen the leg so it still lands exactly on 2180:

\begin{center}
\footnotesize
\begin{verbatim}
2180                     = iteration 3,162,240   (checkpoint OK)
nearest checkpoint ~2170 = iteration 2,986,560   (= 2040 x 1464)

forward leg :  nIter0 = 2986560,  nTimeSteps = 175680   (10.03 yr)
                       `-- writes pickup.0003162240
adjoint     :  nIter0 = 3162240,  nTimeSteps = 87840    (5 yr, 2180 -> 2185)
\end{verbatim}
\end{center}

The general rule for a different checkpoint is
\textbf{\code{nTimeSteps = 3162240 $-$ nIter0}}, so the leg always terminates on
the reference start.

\begin{callout}
\textbf{Filename collision.} The member's forward leg writes
\code{pickup.0003162240}, the same iteration number as the reference pickup,
because that is the point of the design. Keep each member in its own run
directory and never stage two into a shared one.
\end{callout}
